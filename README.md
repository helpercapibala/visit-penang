# Visit Penang - Web Application

A responsive web application designed to explore tourist attractions, local food, and cultural spots in Penang.

## Features
- **Attractions & Food Guide:** Browse popular spots and local recommendations across Penang.
- **Interactive UI:** Dynamic interface with responsive design for desktop and mobile screens.
- **Detailed Views:** Categorized views and detailed insights for various tourist locations.

## Tech Stack
- **Frontend:** React, JavaScript (ES6+), HTML5, CSS3
- **Tools:** Visual Studio Code, Node.js, Git, GitHub

## Getting Started

### Prerequisites
- Node.js installed on your machine

### Installation & Run
## 1. Clone the repository:
   ```bash
   git clone [https://github.com/helpercapibala/visit-penang.git](https://github.com/helpercapibala/visit-penang.git)
   ```

## 2. Navigate into the directory and install dependencies: 
```bash
cd visit-penang
npm install
```

## 3. Start the local development server: 
```bash
npm start
```
